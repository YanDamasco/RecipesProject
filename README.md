# Aurora Restaurant

## Descrição

O Aurora Restaurant é um site institucional criado para apresentar um restaurante sofisticado e moderno. O objetivo do projeto é transmitir a experiência gastronômica refinada do estabelecimento por meio de uma navegação intuitiva, design elegante e seções informativas que destacam seus diferenciais, cardápio e filosofia.

## Ferramentas utilizadas

O projeto foi desenvolvido utilizando as seguintes tecnologias:

HTML5 e CSS3: responsáveis pela estrutura e estilização completa do site, garantindo um layout organizado e visualmente agradável.

JavaScript: utilizado para implementar funcionalidades interativas, como a seção de avaliações (Reviews) e o menu responsivo (Burger Menu) que se adapta a diferentes tamanhos de tela.

Vercel: plataforma de hospedagem utilizada para disponibilizar o site na nuvem, tornando-o acessível publicamente de forma prática e confiável.

## Propósito do projeto

Este projeto foi desenvolvido com o objetivo de expandir minhas habilidades em desenvolvimento web, aprimorando conhecimentos em criação de layouts, boas práticas de organização de conteúdo, técnicas de responsividade e processos de deploy em plataformas modernas como o Vercel.

# Aurora Restaurant

## Description

Aurora Restaurant is an institutional website designed to showcase a modern and sophisticated restaurant. The goal of this project is to convey the restaurant’s refined gastronomic experience through intuitive navigation, elegant design, and informative sections that highlight its specialties, menu, and philosophy.

## Tools & Technologies

The project was built using the following technologies:

HTML5 & CSS3: for the complete structure and styling of the website, ensuring a clean and visually appealing layout.

JavaScript: used to implement interactive features such as the Reviews section and the responsive Burger Menu that adapts to different screen sizes.

Vercel: hosting platform used to deploy the website to the cloud, making it publicly accessible in a reliable and practical way.

## Project Purpose

This project was developed to enhance my web development skills, improving my knowledge of layout creation, content organization best practices, responsive design techniques, and deployment processes on modern platforms such as Vercel.
